# Contributing

Open an issue or pull request describing the behavior you want to change. Follow AGENTS.md and run the checks relevant to your change. Include reproduction steps and test evidence; identify real-device results separately from fixtures.

Keep target registration, signing and scheduling portable. Never commit credentials, profiles, pairing files, generated transport binaries, local Xcode configuration or private repository source. Preserve third-party notices when changing dependencies. Code contributions are provided under the repository's MIT license.
