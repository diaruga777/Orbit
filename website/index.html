A FEW GOOD QUESTIONS

Before you
take off.

Do I need a paid Apple developer account?

No. Orbit supports free Personal Teams for compatible apps. Apple allows three development apps per device, and Orbit itself uses one slot. Free profiles expire after seven days; Orbit’s Mac refresh schedule defaults to six.

Does my Mac need to stay on?

For new builds and scheduled Mac installs, it needs to be awake, logged in, and able to reach your trusted phone. Optional phone refresh can renew a previously cached build without the Mac. New code still needs a Mac build.

Can I install any app from GitHub?

You need a working iOS Xcode app project and a runnable scheme. Some apps need paid entitlements, private dependencies, or extra setup. Only build repositories you trust: their build scripts run on your Mac.

Can I use Orbit with my coding assistant?

Yes. Orbit includes a local MCP service, CLI, and setup skills so compatible agents can add projects, build apps, and check jobs. You can also use Orbit yourself, without an AI subscription.

What do I need to get started?

A Mac running macOS 15 or later, Xcode 26.2 or newer, and an iPhone or iPad running iOS or iPadOS 26 or later. Setup guides you through Apple sign-in, device trust, and Developer Mode.
