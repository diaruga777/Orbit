# Security

Orbit can edit files and run trusted Xcode projects with your Mac account's permissions. Review source before adding a target. Pair only your own phone and compare its identity in both clients. Protect your Mac user account and private state directory; access to them can control Orbit's local MCP.

Do not attach Apple account passwords, tokens, signing keys, provisioning profiles or device pairing records to public reports. Use the GitHub repository's private vulnerability reporting feature when available; otherwise ask the maintainer for a private reporting channel without posting exploit details or credentials publicly.

Revoking Orbit phone trust removes its app-level access and installation authorizations. It does not revoke Apple's independent device pairing or a Tailscale session; manage those through their respective tools.
